# Shreyas Vinod Kumar — Portfolio Website

A responsive, single-page portfolio built with HTML, CSS, and JavaScript. Designed in a charcoal, orange, and gold palette with animated visuals and certificate category filters.

## Files
- `index.html` — page content
- `style.css` — styling and responsive layout
- `script.js` — navigation, scroll reveal, certificate filters, and back-to-top button
- `certificates/` — add your certificate files here using the exact names below

## Publish with GitHub Pages
1. Extract this ZIP.
2. Open GitHub and create a new **public** repository named `shreyasvk1202.github.io` (or use another repository name if you prefer).
3. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `certificates` folder to the repository root. Do not upload the ZIP itself as the only file.
4. In the repository, go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**; choose `main` and `/(root)`, then save.
6. Wait for the deployment to finish. For a repository named `shreyasvk1202.github.io`, the expected URL is `https://shreyasvk1202.github.io/`. For another repository name, the URL will usually be `https://shreyasvk1202.github.io/REPOSITORY-NAME/`.
7. Test the page on both desktop and mobile, and click every certificate link.
